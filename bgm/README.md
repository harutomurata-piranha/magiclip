# BGM（CC0 / クレジット表記不要）

このフォルダに **CC0ライセンス（著作権フリー・クレジット表記不要）** のBGMを置くと、
AIが提案した `bgm_mood` に応じて自動で選曲・ミックスされます。

## 入手先（おすすめ）

- Pixabay Music … https://pixabay.com/music/  （Pixabay Content License：商用可・帰属表示不要）
- その他、CC0 / パブリックドメインの音源

> ⚠️ ダウンロード時に各音源のライセンス表記を必ず確認してください。
> 「No attribution required」「CC0」「Pixabay License」のものを選べばクレジット表記は不要です。

## ファイルの置き方

ダウンロードしたmp3を、以下のカテゴリ名にリネームして直下に置いてください。

| ファイル名         | 想定ムード（bgm_mood）                       |
|--------------------|----------------------------------------------|
| `bright.mp3`       | 明るい / 楽しい / ポップ / 元気               |
| `emotional.mp3`    | 感動的 / エモい / 壮大                        |
| `tense.mp3`        | 緊張感 / シリアス / ドラマチック             |
| `stylish.mp3`      | おしゃれ / chill / 落ち着いた / リラックス   |
| `comical.mp3`      | コミカル / ユーモラス                         |
| `default.mp3`      | （任意）上記が無いときのフォールバック        |

- 該当ファイルが無いムードは、`default.mp3` → それも無ければ **BGMなし** で書き出されます。
- 音量は元の音声を保ったまま `volume=0.15` で低音量ミックスされます（`mix_bgm` の引数で調整可）。

mp3ファイル本体は `.gitignore` で除外されます（このREADMEのみ追跡されます）。
